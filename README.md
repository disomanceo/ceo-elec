# Electricity Daily Log

เว็บบันทึกค่าไฟฟ้ารายวันสำหรับตรวจสอบการใช้ไฟฟ้าและค่าใช้จ่าย

## ฟังก์ชันหลัก
- บันทึกวันที่
- บันทึกหน่วยเริ่มและหน่วยจบ
- คำนวณหน่วยที่ใช้ = หน่วยจบ - หน่วยเริ่ม
- กำหนดราคาต่อหน่วย
- คำนวณค่าไฟรวม = หน่วยที่ใช้ × ราคาต่อหน่วย
- แก้ไข/ลบรายการ
- สรุปวันนี้ เดือนนี้ และยอดสะสม
- กราฟหน่วยใช้รายวันและค่าใช้จ่ายรายวัน
- กรองข้อมูลตามช่วงวันที่
- ส่งออก CSV
- รองรับมือถือและเดสก์ท็อป
- เก็บข้อมูลใน localStorage เพื่อใช้งานได้ทันที

## วิธีรัน
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## โครงสร้างระยะถัดไป
สามารถแยก Data Layer แล้วเปลี่ยนจาก localStorage เป็น Supabase เพื่อรองรับหลายอุปกรณ์/หลายผู้ใช้ รวมถึงเพิ่มสถานที่หรือห้อง เช่น ห้องเรียน อาคาร หรือมิเตอร์ย่อยได้
